# tribe-updates

Обновления тестовых сборок игры «Племя» (Godot 4).

- `version.json` — что сейчас актуально: базовая сборка, номер патча, хеш и размер файла.
- `patches/` — патч-пакеты (`.pck`), только изменённые относительно базовой сборки файлы.
- APK базовых сборок — в Releases.

Файлы выкладывает скрипт `tools/publish-update.sh` из репозитория игры. Руками не править.
